# Codex Switcher

一个简洁的 macOS 账号限额查看与切换工具，复用 `~/.codex/switch-account.sh` 的安全切换规则。

## 功能

- 查看当前账号或中转站。
- 查看所有账号的 5 小时额度、周额度、重置时间和重置卡。
- 所有账号直接显示在同一页面，账号较多时纵向滚动。
- 自动标出下一个推荐账号，并排除当前账号。
- 按钮切换指定账号。
- 全量“立即刷新”时账号之间间隔 1 秒，每个账号也可单独立即查询。
- 周额度仍有剩余时，5 小时重置时间一到会自动查询该账号一次。
- 可增加账号、设置显示别名，并在鼠标停留时查看原用户名和邮箱。
- 可将非当前账号的凭据移到废纸篓。
- 可填写自动查询间隔，并在秒和分钟之间切换；默认 1 分钟。
- 单个账号查询失败时保留已有数据并显示错误。
- 带有适配 Finder 和 Dock 多种尺寸的应用图标。

## 构建

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
```

应用生成在 `dist/Codex Switcher.app`。当前使用本机临时签名，适合个人使用。

运行核心逻辑检查：

```bash
swift run CodexSwitcherCoreChecks
```

## 使用前提

- 已安装 `~/.codex/switch-account.sh`。
- 增加账号前需先保存工作并退出 Codex CLI；应用可以关闭并重新打开 ChatGPT 桌面端，但不会强制结束 CLI。
- 新账号登录后，应用在本地从 `auth.json` 的身份令牌中读取用户名和邮箱；不会显示令牌内容。
- 添加过程中点击取消，会先停止检测并关闭登录应用，再恢复原账号和账号记录；取消提示在 4 秒后消失。恢复后可自行重新打开 ChatGPT。
- 如果取消时新凭据已经生成，应用会丢弃它并恢复旧账号；需要添加时可重新在 ChatGPT 中登录。
- 登录应用未能退出时不会强行覆盖凭据；退出它后可再次点击取消重试。添加期间请保持 Switcher 运行，本次恢复流程不包含强制退出或系统崩溃后的自动恢复。
- 切换账号后需要完全退出并重新打开 Codex。
